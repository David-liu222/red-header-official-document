# 红头公文验收清单

## 自动检查

- [ ] 输出文件是新文件，源文件未被覆盖。
- [ ] 已先判断真实表格数量：`w:tbl=0` 时走无表格分支，`w:tbl>0` 时走有表格分支；报告写明分支结果。
- [ ] 文件名与正文标题完全一致，除非用户明确指定后缀。
- [ ] A4 页面；四边页边距落在目标范围或报告已记录偏差。
- [ ] 标题黑体二号、不加粗，使用“正文文本/Normal”样式；在 WPS“段落”窗口中，段前、段后均明确显示为 `0 行`，不得显示为“自动”或 `0 磅`。
- [ ] 红头宋体、45 磅、红色、加粗、居中；红头字体不得擅自替换为其他“常用公文红头字体”。
- [ ] 正文仿宋四号；正文加粗状态与同类正式定稿一致。按 66 号《复函》样式，正文主体不加粗、主送单位加粗。
- [ ] 正文段前、段后均为 0；首行缩进约 2 字符。
- [ ] 行距采用已确认模式；未确认时报告固定 27 磅默认。
- [ ] 主送单位、外发/内发判断、迎检备注互相一致。
- [ ] 网页字段和原稿可见字段已比对；标题、文号、主送、落款、日期冲突已写入报告。
- [ ] 发文字号缺失时，输出文件和报告均明确标记为待补文号审阅稿。
- [ ] `outputMode` 已执行；需要 PDF/旧 DOC 时已转换或写明未能转换原因。
- [ ] 层级序号没有跳级、混用错误或错误标点。
- [ ] 条目正文不用 `；` 结尾；书名号之间没有顿号。
- [ ] 附件与结束语之间空一行；结束语无句号。
- [ ] 公司名、矿名/部门名和日期落款按规则分行、居中、留空行。
- [ ] 页码、红头和右下角落款按模板处理。
- [ ] 无表格分支未运行表格脚本、未写入表格分页/表头重复/行高/单元格属性。
- [ ] 有表格分支已分区处理：公文区按公文规则调整；表前说明与紧随表格分页联动；表格本体未套正文格式。
- [ ] 有表格分支已结构对比：表格文字、行数、单元格数、合并、列网格、斜线数量未变化；所有表格外框、内部横线、内部竖线、单元格边框和已有斜线边框均已强制为 `single` 实线；若任何表格内部行高/行距/列宽被改动，已有用户明确确认。
- [ ] 有表格分支不得残留 `w:tblpPr` 浮动定位/文字环绕；渲染后不得出现后续正文挤在表格左侧、竖向逐字换行、与表格并排绕排或重叠。
- [ ] 能整页容纳的表格未被拆页；不能整页容纳的表格跨页时保留或添加了原首行重复表头，且未复制新普通行、未拆成多张独立表。

## 人工渲染检查

- [ ] 红头颜色、红线、标题位置和主送单位位置正常。
- [ ] 标题换行没有拆词，正文无压线、溢出、异常空白页。
- [ ] 页面视觉上“上长下短”，落款和日期没有挤到页底或脱离正文。
- [ ] 多页页码连续且位置一致。
- [ ] 附件编号、附件名称和分页符合用户要求。
- [ ] 旧 `.doc` / PDF 转换后字体没有替换、乱码或字形缺失。

## 交付报告

交付时分成三组写明：

1. 已自动检查并通过的项目。
2. 已渲染、但需要人工目测确认的项目。
3. 因当前规则缺失或冲突而待用户确认的项目。

网页任务还必须写明：

- 任务编号和来源文件数量。
- 使用的标题、文号、主送单位、发文类型、落款单位和成文日期。
- 输出文件清单。
- 未确认字段不得写成“已满足”。
